iDrive BFF 서버 개발

사우디아라비아 최초 렌터카 및 공유앱 iDrive에, 자사 Raidea 서비스를 고객에 맞게 커스텀한 BFF(Backend For Frontend)를 개발해 앱에 적용했습니다. 예약 BFF 도입으로 기존 AWS 네트워크 비용 약 20% 절감 효과를 기대했습니다.

  • TypeScript
  • NestJS
  • React
  • React Native

  1. iDrive 전용 BFF(Backend For Frontend) 서버 개발2022.06 ~ 2022.12

01

iDrive 전용 BFF(Backend For Frontend) 서버 개발

2022.06 ~ 2022.12 (6개월)

개요

자사에서 서비스 중인 Raidea 서버를 다양한 고객사별로 지원할 수 있도록, 고객사별로 구축하는 중간 Gateway 서버를 개발했습니다.

담당 업무

  • 예약 관련 API 로직 개발 (예약 취소, 대여, 반납, 조회)
  • FAQ, 약관 API 로직 개발

주요 성과

NestJS/TypeScript로 처음 진행하는 프로젝트여서, 가이드라인이 될 예제 코드를 먼저 제공해 팀원들이 참고하며 개발할 수 있도록 했고, 이를 통해 팀 내 개발 프로세스에 기여했습니다.

02

iDrive 전용 BFF 요청 App에 적용

2022.12 ~ 2023.03 (4개월)

개요

개발한 BFF 서비스를 App에서 호출하도록 기존 App의 요청 부분을 수정했습니다.

담당 업무

  • 예약 관련 요청 로직 수정 개발 (예약 취소, 대여, 반납, 조회)

주요 성과

백엔드 개발자이지만 React와 React Native를 학습해 기본적인 App 코드 수정이 가능하도록 했고, 추가 인력 투입 없이 App 수정 개발을 진행할 수 있게 해 회사의 직접적인 매출에 기여했습니다.
