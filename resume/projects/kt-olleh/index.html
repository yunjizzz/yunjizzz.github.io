01

KT 서버 업그레이드에 따른 자사서비스 migration 프로젝트

2020.05 ~ 2020.09 (5개월)

개요

자체 솔루션인 셋톱박스 내부 미들웨어가 운영되고 있는 서버의 버전 업그레이드(JEUS 6 → JEUS 7)에 맞춰 기존 서비스를 적용하는 작업입니다.

담당 업무

  • 서버 이전에 따른 기존 서비스 모듈 적용
  • 기존 잔여 이슈 수정 (날짜 포맷, 이상 데이터 삭제 등)
  • 관련 기능 전체 검수 및 성능 테스트
  • 개발 관련 고객사(KT), 협력사(휴맥스) 대응 및 업무 지원

주요 성과

서버 버전 업그레이드 작업 중 오류가 발생했고, 원인을 파악하던 중 Tmax 내부 솔루션에 문제가 있는 특정 케이스를 확인하여 고객사 및 협력사에 오류 현상을 리포트했습니다. 해당 오류가 반영된 협력사 솔루션을 적용해 문제를 해결할 수 있었습니다. 이 문제를 자사 솔루션 자체의 문제로 보고 고객사가 페널티 비용을 청구했으나, Tmax 특정 버전의 문제임을 확인하여 해당 비용을 협력사가 부담하게 되었고, 회사 매출에 직접적으로 기여했습니다.

02

KT 자사 모듈 DB 제거 후 File system 변경 프로젝트

2020.09 ~ 2020.12 (4개월)

개요

서비스 사용 이력을 관리하는 미들웨어 시스템에서 Oracle DB를 제거하고 File System으로 변경하는 작업입니다.

담당 업무

  • 기존 서비스 영향도를 파악하여 Oracle DB 사용 제거
  • 서버 내부에 날짜별 파일을 생성하여 이력을 관리하도록 변경
  • 이력 서버로 데이터 전송 후 서버 내부 파일을 삭제하도록 스케줄 처리

주요 성과

서비스 이력을 Oracle DB에서 File System으로 변경하여 Oracle DB 사용료를 절감했고, 고객사의 비용 절감과 회사의 솔루션 관리 포인트 절감에 기여했습니다.
