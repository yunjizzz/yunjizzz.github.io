01

LGU+ 멤버스 제휴몰 연동 프로젝트

2019.04 ~ 2019.07 (4개월)

개요

멤버스 서비스 내에 제휴몰 연동 부분을 추가하여, 멤버스 이용 고객에게 제휴몰 서비스를 제공하는 기능을 추가했습니다.

담당 업무

  • 각 제휴몰(파고다, 골프존, 기프티켓, 베베쿡, LF) 연동 가입 및 멤버십 발급 로직, 포인트 조회, 사용 내역 개발
  • 제휴몰 관리자, CMS 페이지 개발

주요 성과

제휴몰 5개 담당 개발자와 원활한 소통을 위해 공통 API 규격을 제시하였고, 해당 규격으로 가입 및 멤버십 발급 로직, 포인트 조회, 사용 내역 개발을 진행하여 프로젝트 개발기간을 단축할 수 있었습니다. 단축한 개발기간만큼 검증 시간을 확보하여 안정적인 서비스 구현에 기여했습니다.

02

LGU+ 멤버스 개인화 프로젝트

2018.12 ~ 2019.03 (4개월)

개요

고객 분석 데이터를 이용하여 고객별 맞춤 메인 화면을 제공하는 서비스를 개발했습니다.

담당 업무

  • 고객별 맞춤 배너 서비스 관리자 사이트 개발
  • 고객별 맞춤 배너 조회 API 로직 개발

주요 성과

고객별 맞춤 배너 서비스의 연령별, 관심사별 전체 Test case를 검증할 수 있도록 모든 케이스에 대한 테스트 데이터 SQL 작성 및 TC를 미리 준비하여, 고객사 서비스 검증 시 검증 시간 단축 및 고객사의 개발 신뢰도 상승에 기여했습니다.

03

LGU+ 멤버스 서버구조 고도화 프로젝트

2018.07 ~ 2018.12 (6개월)

개요

서버 장비 교체, 주요 라이브러리 업그레이드 및 웹서버 구조 개선을 진행했습니다.

담당 업무

  • 주요 라이브러리(Log4j) 및 JAVA 버전 업그레이드 (1.6 → 1.8)

주요 성과

팀 내 주요 라이브러리 업그레이드 적용 후 발생한 오류의 원인 파악에 어려움이 있었으나, 해당 부분을 먼저 발견하여 팀 내 개발시간 단축에 기여했습니다. 당시 오류는 특정 라이브러리가 또 다른 라이브러리의 특정 버전에 의존하고 있어 발생한 문제였으며, 두 라이브러리 버전은 유지하는 것으로 처리했습니다.

04

LGU+ 멤버스 DB구조 고도화 프로젝트

2018.06 ~ 2018.10 (5개월)

개요

DB 버전 업그레이드 작업(Oracle 10g → Oracle 12c)을 진행했습니다.

담당 업무

  • 과부하 쿼리 튜닝 및 성능 개선
  • 기존 ORACLE 스케줄러에서 관리하던 파티션 테이블을 JAVA 배치를 이용한 파티션 테이블 관리 기능으로 추가 개발

주요 성과

서비스에서 사용 중인 모든 DB 쿼리를 추출하여 Query Plan을 확인함으로써 개인적으로 전체 서비스 구조 파악에도 도움이 되었고, LG CNS DBA와 함께 작업을 진행하며 Query 관련 정보를 많이 습득했습니다. 이후 팀 내 통계데이터 및 복잡한 구조의 SQL Query 개선을 담당하며 팀 내 통계 DB 담당자로 기여했습니다.

05

LGU+ 멤버스 기능개선 프로젝트

2018.03 ~ 2018.06 (3개월)

개요

통합 서버 오픈 후 개선 요구 사항에 대한 추가 개발을 진행했습니다.

담당 업무

  • 가입자에 대한 통계 세분화(연령, 성별, 통신사 등) 수집 배치 프로그램 개발
  • 관리자 및 제휴사 홈페이지 통계 세분화 페이지 추가 개발
06

LGU+ 멤버스 통합서버 프로젝트

2017.06 ~ 2018.02 (7개월)

개요

스마트월렛, 소액결제, U+멤버십, 통신료납부 4개의 앱을 U+멤버스라는 앱으로 통합하는 프로젝트입니다.

담당 업무

  • 관리자 사이트 공통 라이브러리 개발하여 코드 간결화 진행
  • 고객 1:1 문의 API 기능 및 관리자 1:1 문의 답변 및 관리 기능 개발
  • 제휴사 멤버십 및 쿠폰 연동 API 개발

주요 성과

기존 관리자 페이지 모든 파일에 동일한 코드가 존재하여, 하나의 코드를 수정할 때 모든 페이지를 수정해야 하던 부분을 하나의 페이지로 분리하고, 해당 페이지에서만 수정하면 전역으로 처리되도록 변경하여 개발 편의성에 기여했습니다.
